================================================================================
ARCHITECTURE NOTES (do not re-litigate these without a real bug)
================================================================================
- LocalStorage key: "learningApp" (matches spec). Single JSON blob, typed as
  AppState in types/index.ts.
- lib/store.ts is the ONLY module that mutates the cached state reference;
  hooks/useAppData.ts is the ONLY hook components should use to read it.
- lib/actions.ts holds pure (state) => state transitions. hooks/useActions.ts
  wraps them with the store setter + toast celebrations. UI components never
  call lib/actions.ts directly — they go through hooks/useActions.ts.
- AI: UI/hooks only ever import services/ai/index.ts (getReviewService).
  Nothing outside services/ai/* knows Gemini exists. XP is always computed by
  lib/xpEngine.ts from the AI's scores — providers never emit XP themselves.
- Skill "completion %" formula and the leveling curve are documented inline
  in lib/roadmapEngine.ts and lib/xpEngine.ts respectively.
